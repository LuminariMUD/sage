# Draw.io diagram exports

These files convert the compressed draw.io drafts into formats optimized for text search, lore analysis, and relationship editing. The extensionless originals remain unchanged.

Each diagram has:

- A Markdown knowledge map with Mermaid topology, normalized labels, VNUMs, nodes, and explicit connections.
- An uncompressed `.drawio.xml` companion preserving the exact graph model, geometry, styles, and routing metadata.
