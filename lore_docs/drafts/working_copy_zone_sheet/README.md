# Working Copy of Zone Sheet — extracted worksheets

Source workbook: [`../Working Copy of Zone Sheet.xlsx`](../Working%20Copy%20of%20Zone%20Sheet.xlsx)

Each Excel worksheet is stored as a separate Markdown file for direct text search and reliable AI reading. The original workbook is unchanged.

Export conventions:

- Tables preserve original Excel row numbers and column letters, including intentionally blank cells inside the used range.
- Formula cells show the workbook’s cached value in the main table and retain the original expression in a **Formula cells** appendix.
- Dates and times use unambiguous ISO formatting.
- Embedded hyperlinks, comments, merged ranges, hidden rows/columns, and non-white fill colors are retained in metadata sections.
- Worksheet rows or columns containing only formatting beyond the last populated cell are omitted.
